# 底部多行实时浮窗：方案与验收

状态：EGM 独立评审与定向复核已完成；负责人于 2026-11-10 回复“准”，已实施并安装，交互验收进行中。

## 建议

采用**屏幕下方停靠、2—4 行自动换行、遇输入区时向上避让**。沿用 ChatType 现有配色、图标、波形、F5、ESC、关闭与 Retry；完整转写、整段润色及最终插入流程保持当前版本。

使用场景是用户在聊天框、编辑器或其他可编辑目标中连续讲话，需要读到最近一句，同时继续操作输入区与发送按钮。优先级：输入区/发送控件可操作 → 文字可读 → 底部位置与会话内稳定。

## 取舍

| 布局 | 收益 | 代价 | 选择 |
| --- | --- | --- | --- |
| 屏幕底部正中固定 | 视线落点稳定 | 与聊天输入框、发送按钮、Dock 同处下方 | 作为无碰撞时的默认位置 |
| 固定左下或右下 | 中央输入区较空 | 常遇侧栏、新建/附件、浏览器下载等控件 | 只作为可用空间候选 |
| 下方默认 + 输入区避让 + 可拖动 | 兼顾底部偏好和实际应用布局 | 需可靠测量、稳定锚点及未知布局出口 | 建议采用 |

## 位置与避让

1. **屏幕与安全区**：录音开始时沿用现有屏幕选择（焦点窗口所在屏幕，继而鼠标所在屏幕），会话中锁定。使用该屏幕 `visibleFrame` 避开当前 Dock/菜单栏，初始底边距建议 16pt。屏幕拔插或可用区域改变时重新约束位置。
2. **保护区域**：仅用已授权的公开 Accessibility 接口读取当前焦点可编辑区域、光标范围和所属窗口几何。对聊天式小输入框，保护与输入框同高度的窗口底部整行并向上下扩 12pt，覆盖发送、附件等相邻控件；对占据窗口大部分面积的文档编辑区，优先保护光标附近及窗口底部工具行，避免把整个文档当成禁放区。
3. **候选选择**：先尝试底部中央；与保护区域相交时，先选择输入行上方至少 12pt 的位置，横向保持居中。空间不足再比较左下/右下可用区。以**四行最大包络**检查碰撞，避免文字增长后重新盖住按钮。
4. **空间/信息不足**：先缩窄文字列，仍冲突则用两行紧凑布局；可选位置均相交或编辑器不提供可靠几何时，左下紧凑位置进入“需要调整位置”状态，保留明确拖动手柄。验收记录此时是否遮挡，再拖动并实际点击原按钮；人工调整后获得可用位置才通过。整个屏幕均无容纳空间时，该环境验收失败并停止该环境的发布判定。自动避让通过、人工调整通过、失败分别记录。
5. **稳定与拖动**：普通文字更新、标点变化、鼠标移动和识别回改保持锚点。焦点窗口/输入框位置或 Dock 安全区变化造成碰撞时才迁移。用户可拖动底部操作栏的空白手柄区域。拖动期间暂停自动迁移，转写继续更新；松手后约束到屏幕内，对已知保护区域作一次避让。该位置成为本次录音的新锚点；后续输入框/屏幕几何变化产生新碰撞时再做一次必要避让。再次拖动仍先暂停自动迁移。后续录音重新按默认策略布置，正常识别不触发自动横跳。

位置决策优先使用当前已存在的 AX 授权，增加几何读取不新增系统权限。实际实现须在原生多屏坐标转换处复用现有测试；应用输出的 AX 数据作为位置线索，最终以目标控件实际可点为验收。

## 多行与交互

- **结构**：文字区位于上方，固定操作栏位于下方（原波形/状态、计时、拖动区域、关闭/Retry）。操作栏底边与屏幕锚点固定；文字区增加行数时，仅面板顶边向上扩展，关闭、计时、Retry 的屏幕坐标保持一致。文字与按钮各自占用布局区域。
- **尺寸建议**：常规宽 480pt，依可见屏幕宽收缩；正文 14pt、行高约 20pt。初始容纳两行，内容自然增加至四行；浮窗底边固定、向上增长。实际宽度与文字测量使用 AppKit 排版结果，含中文、英文、标点和缩放。
- **长文本**：超过四行后滚动查看，完整会话文本保留；自动跟随末尾。用户主动向上滚动时暂停跟随，显示“回到最新”入口；回到底部后恢复跟随。长英文、路径与 URL 超过行宽时允许字符级换行，显示保留完整字面量。
- **更新**：partial 在原片段更新，final 固定已有文字；普通识别修订不移动窗口、不抢焦点、不改变剪贴板。
- **点击与键盘**：浮窗沿用 nonactivating 行为。按钮和滚动在自身面板内工作；所有底层关键按钮通过空间避让获得可点击区域，不依赖模拟穿透或自动转发点击。F5/F5、ESC 和内联关闭沿用当前动作。
- **状态连续**：转为润色时保留本次已定稿文字，状态栏显示处理中；成功显示已粘贴/已复制状态后按现有策略收起。错误保留原文字并显示现有错误/Retry。取消后隐藏，下一次录音清空旧文字。

两至四行是预览窗口的建议可视高度，完整文本和录音继续保留。作为新增展示约束，应在后续 PR「新增限制」写清尺寸、默认值与依据，随本方案由负责人定稿。

## 验收

### 设计核对

交付短句两行、长段四行、超长滚动、处理中、Retry 五个状态的前后对照。每张画面同时显示浮窗、实际输入区、发送/附件按钮与 Dock，标明保护区域和最终坐标。字体、换行、图标和配色在安装版实看。

### 安装版场景矩阵

| 场景 | 必须观察到的结果 |
| --- | --- |
| 聊天窗口底部有输入框、发送、附件按钮 | 讲话中持续出字，保护区域与浮窗实际框无交集；按钮可直接点击并保持原功能 |
| 文档编辑器、长文本或终端编辑输入 | 光标附近内容可见；两行至四行自然换行，正文增长不盖住必要工具栏 |
| 短句、中英混输、长路径/URL、120 秒长段 | 换行可读，文字完整保留；默认跟随末尾，回看与“回到最新”互不抢滚动 |
| Dock 在下/左/右及自动隐藏 | 停靠区与浮窗位于有效可见范围；呼出 Dock 时重新检查位置，浮窗控制仍可达 |
| 内置屏、外接屏、缩放、多屏负坐标与拔插 | 使用目标屏幕，边界约束正确；普通鼠标跨屏不搬动录音浮窗 |
| 窗口尺寸变化、输入框展开、焦点变化 | 新碰撞出现时才做一次必要迁移；纯文字更新无窗口跳动 |
| 拖动中持续转写、松手后输入框展开、再次拖动 | 拖动中窗口跟随手柄；松手后新碰撞只触发一次避让；再次拖动暂停自动迁移，键盘焦点保留，原按钮可点击 |
| AX 几何缺失/不可用、所有候选拥挤 | “需要调整位置”与拖动入口可用；记录初始状态，再人工调整并实际点击目标按钮；无安全位置时记失败并停止该环境的发布判定 |
| F5/F5、ESC、内联关闭、取消重入、错误 Retry | 行为与当前版本一致；无晚到文字/粘贴，无旧会话残留，原录音可恢复 |
| 编辑器有焦点 / 没有可编辑焦点 | 完成时一次正确粘贴 / 剪贴板结果；预览、拖动和滚动均不提前改写目标 |

关键按钮相交面积为零、原目标窗口保持键盘焦点、自动更新不移动锚点、全部文本可回看，是本次改动的硬验收项。未知布局需在实际应用完成该项核对；方案不对尚未覆盖的任意应用宣称避让成功。
