Mode: Operate. Existing native identity, code-led implementation. Scope: settings window only; retain brand assets and F5 workflow.

## Direction contract

THESIS: Show which account performs each step, then let the user adjust that step. Each setting has one home.

OWN-WORLD: Native system type, existing blue selection, light system sidebar and content background, thin separators, compact form rows. Existing icons and brand colors remain unchanged.

STORY: Connect in Account; understand recording → transcription → polish → output in Dictation; maintain words in Terminology; recover in History; manage local behavior in Settings.

FIRST VIEWPORT: A narrow left sidebar with five destinations and F5 cue. A compact breadcrumb sits above the page title. Account opens on account state, followed by transcription service and polish service rows. Controls sit beside the facts they change. Save state is visible in the bottom bar.

FORM: Native sidebar and grouped form, chosen from the explicit brief and Magpie reference. Signature interaction: select a stage in the processing trail to inspect its input, output, model and destination. seed: none (unavailable).
