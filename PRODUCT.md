# Product

## Platform

Native macOS (AppKit and SwiftUI), macOS 13+.

## Users and purpose

ChatType is a personal studio dictation app for writing into the currently focused app. F5 starts and stops recording; results paste into an editable target or remain in the clipboard. Settings should make services, data movement and recovery understandable in one visit.

## Capabilities and constraints

On macOS 26+, Apple SpeechAnalyzer supplies live preview. Complete audio goes to the original ChatGPT account for final transcription, then terminology alignment and optional whole-transcript text polish. The existing user-selected compatible recovery route remains available. Account credentials live in Keychain. Terms are canonical spellings; Replacement is explicit text correction. macOS keyboard shortcuts belong to macOS.

## Brand commitments

Preserve the product name, app icon, dynamic menu-bar icon and existing system colors. The requested reference is yetone's Magpie: readable account/model rows, clear current state and restrained navigation. The requested character is a useful, candid personal studio product. Prefer precise language over promises and disclose private backend dependencies and data destinations.

## Success

Five focused pages, visible processing flow, responsive large vocabulary editing, working WeChat name import and an honest login-item control. Verify the signed app at /Applications/ChatType.app and leave it running with Settings visible.
